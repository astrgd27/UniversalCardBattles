# Universal Card Battles

A universal, fully automated trading-card-game simulator: a deterministic TypeScript rules engine that runs any card game defined as a JSON module.

```
npm install
npm run check            # typecheck + tests
npm run sim spark-duel   # 200 random-AI games
npm run dev              # play in the browser (hot-seat or vs AI)
npm run e2e              # browser smoke test
```

Making a game: `docs/AUTHORING.md`. See `docs/STATUS.md` for progress, `docs/DSL.md` for the module format and `docs/SPEC.md` for the design.
